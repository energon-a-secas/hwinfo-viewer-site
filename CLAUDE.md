# CLAUDE.md — Hwinfo Viewer

HWiNFO Viewer — HWiNFO CSV log visualizer with crash detection, performance-limit flags, load baselines, and a phased PC validation toolkit with Xid reference (hwinfo.neorgon.com)

**Live:** hwinfo.neorgon.com · **Port:** 8826

## Run

```bash
make serve
```

Then open http://localhost:8826. It must be served over HTTP — the app is ES modules, and `file://` blocks them.

## Architecture

| Module | Lines | Owns |
|---|---:|---|

Vendored from `packages/neorgon-ui/` — never edit in place, run the sync script instead: `js/neorgon-footer.js`, `js/neorgon-header.js`.

## Data

No persisted state — everything lives in memory for the session.

## Conventions

- Zero build step. Plain ES modules loaded by `js/app.js`.
- Header and footer come from the shared kits. Do not add site-local `.neo-footer` or `.header-bar` CSS.
- No single JS file over ~500 lines. It currently holds.
