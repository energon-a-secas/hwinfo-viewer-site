These are trimmed from actual HWiNFO crash logs (sensor columns only) so they load instantly and work offline. Each shows a different failure signature.

How it works

LogScope reads a HWiNFO sensor log, auto-detects the GPU/CPU/PCIe metrics, and gives you four things: an Overview with plain-language insights and a crash verdict, interactive Charts, Baselines that bucket samples into idle/low/medium/high load, and a Translate glossary. New to the tools? Start with the Tutorials tab.

Insights

Automatic read of the log: crash signature, PCIe stability, power delivery, and thermals.

Key numbers

Peaks and lows for the sensors that matter most. Colored borders flag values worth a second look.

Time series

Each line is normalized to its own range (0–100% of that sensor's min–max), so different units overlay cleanly. Background shading shows the load zone; the dashed marker is where a hang was detected. Hover for exact values.

Baseline by load zone
